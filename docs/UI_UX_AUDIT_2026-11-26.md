## Design contract
- Palette: neutral light workspace and white cards; indigo reserved for navigation/current selection/primary action. Semantic success, warning and error use text in addition to color. No decorative gradients in operational dashboard.
- Spacing scale 4/8/12/16/20/24; panel radius 12; control 40px, compact 44px. Body 14, secondary 13, metadata 12, panel headings 15, page title 28 (24 compact). On narrow 320px allow wrapping rather than shrinking labels. Avoid fake values or fabricated charts.
- Information architecture: Overview (performance/attention); Accounts (browser + shared); Content (public library); Publishing (queue/review/history/new post); AI Agent (bridge/research/access/settings). Keep authorization boundaries and human consent. Public landing/privacy/terms separate from operator workspace.
- Layout: 320–639 phone, 640–1024 tablet/compact navigation, 1025–1279 desktop shell with list/card content, >=1280 dense tables. No duplicated visible nav. Keep scrollable sidebar and compact safe-area bottom navigation.
- Test acceptance: exact commit CI and Vercel alias, screenshots inspected at representative widths; no document or panel horizontal clipping, accessible click/keyboard actions, filter persists on resize, readable data states, correct active nav, all controls reachable, no approval bypass. Add screenshot artifacts in each engine. Native Safari/Firefox and real account data acceptance still required.
- Remaining: broader CSS consolidation and dark/system design; screen-reader and full keyboard coverage; empty/error/long real content, browser zoom, native iOS Safari and desktop Safari/Firefox; actual visual review of revised screenshot artifacts; release hold until acceptance and explicit next milestone authorization.
