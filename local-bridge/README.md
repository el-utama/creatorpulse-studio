# CreatorPulse Local Bridge
No dependencies beyond Python 3.10+ standard library. Runs on the always-on Hermes host. Keep it in a dedicated OS account/service if possible, separate from the agent shell; do not allow Hermes to read the bridge token or DB files. On Windows use a separate restricted account and NTFS permissions (Unix umask does not provide equivalent ACLs).
## Setup
From repository root, run `python local-bridge/setup.py`. This creates ignored, private local configuration files, using cryptographically random credentials. It does not configure Vercel, start a tunnel or connect TikTok. Do not put generated secrets in chat, Git, model memory, or logs. Store operator key in a password manager. Transfer the agent key only to the Hermes MCP credential configuration; the bridge/vault/operator keys must not be available to the model.
Run `python local-bridge/run.py` to start the bridge. Default 127.0.0.1:8765. Use systemd, a Windows service or equivalent supervisor for continuous operation. Provide an HTTPS reverse proxy/tunnel to exactly /storage/v1; use a stable URL, not an unauthenticated public HTTP listener. The bridge additionally verifies a high-entropy bearer credential. Set request-body limits and rate limits on the proxy. Do not expose the SQLite file or any other port. No tunnel provider is selected or provisioned.
## Vercel
In the existing project, add the five server-only entries from local-bridge/.secrets/vercel.env. The bridge URL must be https://YOUR-HOST/storage/v1. Do not replace existing TikTok credentials, APP_URL or redirect URI. Redeploy. Without the five entries the gateway stays disabled. The generated file contains secret values; keep it private. Retain the encryption key across deployments or existing encrypted records become unreadable.
## Enroll
Open the production dashboard and log into each desired TikTok account as usual. In Integrasi AI Agent, enter operator key and explicitly enroll the active account (maximum three). Then connect Hermes using integrations/hermes. Check list_accounts and analytics. Removing a browser session or logging out does not delete the persistent gateway record; operator can disconnect it via the API. Revoking TikTok authorization is separate.
## Health and backup
Test using the bridge bearer key with POST /storage/v1 and JSON ["PING"]; expected {"result":"PONG"}. Never include the secret in command history. The bridge has no generic SQL or Lua executor: the command-shaped protocol accepts only fixed operations. SQLite WAL persists data across restarts. Use SQLite online backup or stop the bridge and back up the complete database; never copy only the main file while writes are active. Keep encrypted backups and vault key separately. Host/tunnel outage disables enrolled account operations. Do not retry uncertain publications.
Run tests: `python -m unittest discover -s local-bridge -p "test_*.py"`.
