# Product — CreatorPulse Studio

<!-- impeccable:product-schema 1 -->

## Platform
Web application (Next.js / React); desktop work and mobile review.

## Users
A single operator manages several TikTok accounts and reviews work from Hermes. Multiple browser sessions may have different OAuth authorization; shared enrolled accounts are readable after independent operator unlock. Do not imply agency tenancy or public release readiness.

## Product Purpose
Reduce the work between research, selecting content, reviewing an actual draft, approving the exact account/media/caption, publishing once, and verifying the true outcome. The current MVP uses owner-supplied media. Research and supervised local-file Direct Post have passed prior acceptance; autonomous media generation and scheduling remain deferred.

## Operating Context
The operator uses a Mac browser and a separate Windows host running Hermes. Frequent tasks: scan next actions, choose account scope without changing route, compare public performance, open content, review publication queue, and manage integration. Native TikTok mobile playback of the existing test post was owner-confirmed; web playback remains unresolved. Browser-only authorization and enrolled shared data are distinct. Operator lock is not agent offline.

## Capabilities and Constraints
- Existing OAuth, shared read-only registry, local Bridge SQLite, gateway, account-scoped analytics/public videos and explicit manual target selection.
- Agent draft approval, immutable reviewed media, status provenance, no blind retry, pending/uncertain/rejected distinctions.
- Respect all release gates in docs/STATUS.md and AGENTS.md. No new live posts, production promotion, schedule, credential change or host install in redesign.
- Preserve legal text, factual data and error semantics. Do not invent analytics, growth, health or online status.

## Brand Commitments
CreatorPulse Studio. Practical, legible control workspace; neutral surfaces, restrained accent for action and selection. No decorative dashboard widgets or false urgency. English operational labels remain concise; preserve legally meaningful consent and API statuses.

## Evidence on Hand
Verified sandbox baseline 02f5cb0; prior owner recording 26 Nov 2026; rendered cross-engine fixture artifacts from 007164c; owner reports current appearance remains weird. Native authenticated visual acceptance is outstanding.

## Product Principles
1. Action clarity before decoration: next action should be findable quickly.
2. Identity and provenance before convenience: scope is never a publishing target.
3. Operational consistency: one navigation, recognizable controls, predictable state.
4. Fail closed: never imply publication or approval when unverified.
5. Accessibility is essential: readable labels, keyboard operation, mobile touch targets, resilient content, reduced motion.
