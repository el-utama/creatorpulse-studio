# Agent integration
## Hermes
Configure MCP server URL `https://creatorpulse-studio-six.vercel.app/api/mcp` and HTTP Authorization header with **agent** bearer key, injected from your secret store. This server supports stateless Streamable HTTP compatibility through MCP 2025-11-25; use a compatible client. For Hermes consult https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp. Do not give a model the operator key. Tool list intentionally omits approval. Use REST if the client cannot negotiate this protocol. 
## n8n
OpenAPI: /agent-openapi.json. Import telegram-approval.json into a dedicated **non-agent** n8n workflow. The template is inactive, unconnected and has not been tested in a live n8n instance. Set numeric Telegram user ID in Authorized command (otherwise it drops all messages). Select the same Telegram bot credential in trigger and reply nodes. In HTTP Request nodes use separate Bearer Auth credentials: Read draft and Execute approved inbox = agent; Approve exact draft and Status or cancel = operator (status can use operator). Never put operator credentials into an AI Agent node or a workflow callable by the model. Restrict access to n8n editing and execution data. Use a separate bot or a single trusted dispatcher, since Telegram allows one webhook per bot. 
Human sends /review UUID, inspects actual media and target, then /approve UUID to authorize and submit to inbox. /status UUID checks progress; /cancel UUID cancels an unsubmitted draft. Direct public posting is not supported by the gateway. Caption is only a suggestion. If a call times out, use /status and inspect TikTok; do not resend uncertain requests. 
## Trend research
Agent obtains evidence from its authorized web research tools or a properly authorized Discovery API provider. Submit observations using record_trend/POST trends. The gateway is not a Discovery API client. Suggested daily schedule via n8n: collect sourced observations, compare with account analytics, send a digest to an allowed chat. No invented metrics. WhatsApp Business Cloud adapter, live bot, scheduled research, verified media hosting and real TikTok approval/authorization still need setup.
